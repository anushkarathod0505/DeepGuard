# DeepGuard

AI-Based Deepfake Image Detection System

## Description
DeepGuard is an educational prototype
that uses a pretrained Vision Transformer
to classify uploaded images as Real or Fake.

## Technologies
- Python
- PyTorch
- Hugging Face Transformers
- Streamlit

## Run locally

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Model
dima806/deepfake_vs_real_image_detection

Note: This project uses a pretrained model.
Predictions are not forensic proof.
